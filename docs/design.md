# 介面與功能設計

## 介面三原則（作者訂定，所有畫面都以此檢查）

1. **方便設定**：一開始的設定、上傳學習資源（單字表、文法、每週素材、照片）、上傳自己的東西讓 Claude 產課程，都要快而且一眼看得到入口。
2. **讓人想持續使用**：畫面吸引；首頁積分明顯；任務導向（今天要做什麼、離目標多遠）；養成習慣。
3. **文字少、舒服、有後續引導與正向回饋**：操作結束後的下一步主要靠視覺與介面暗示（按鈕、進度、亮起的元件），不是文字說明；說明收進 `?`；完成時給正向回饋。

> 第二版的完整設計（多使用者、積分與等級、AI 對話、每日課程、課程配方、語音、學習群組）在 [`plan.md`](plan.md)；兩者不一致時以 `plan.md` 為準。

視覺語言沿用 PaperComposer 的元件與色彩 token 命名（配色改為 20 組主題，見〈主題〉一節）、同一套線條圖示、左側導覽＋中間「紙張」＋右側助手面板、設定視窗用分頁。JELearner 比 PaperComposer 多了秘書（avatar）、自動爬蟲、資料串聯，以下是整體規劃；標「第一版」的已完成，其他是之後的設計。

## 第二版 A 階段的介面（已完成）

- **左欄**：頂端個人卡（大頭貼可點擊上傳、名字、等級環、今日／總分／連續天數），導覽分組「練習（今日、對話、教材、新聞）／我的資料（生字、文法、錯題本、素材）／進度」；信件與行事曆移到設定 06。
- **今日**：等級環＋今日積分條＋連續天數，下面 3–4 張任務卡（複習、對話、教材測驗、錯題），只有下一個未完成的任務有主要按鈕。
- **結算卡**：完成時 +分數、一句正向回饋、升級徽章、一到兩個下一步按鈕；前 5 課在教材結算卡上問「太簡單／剛好／太難」。
- **對話**：點狀回合進度（最後 3 回合加框）、目標字用到就亮起、AI 的換句話說用淡底色與 ↺、每回合倒數環（打字時只是節奏提示）、日文有句型開頭按鈕、最後一回合後輸入框變成鎖＋「完成」，再顯示回饋卡。
- **進度**：等級環、升級條件 1–3 的進度條、分技能橫條、最近 14 天、主題。
- **匯入**：整個視窗都能拖放，自動判斷單字 CSV／文法 CSV／每週 JSON；頂列上傳圖示、右欄、空白頁面都有入口。
- **元件**：`.level-ring`、`.pts-bar`、`.skill-bars`、`.result`、`.task`；顏色只用主題變數（`--accent-2`、`--accent-3` 未定義時退回 `--accent`）；轉場與完成動畫包在 `prefers-reduced-motion: no-preference` 裡。字級基準 15px。

設定視窗：01 工作區與同步（開啟／建立／下載、Git 狀態、同步、匯出紀錄、重新讀取）、02 個人（名字、週報信箱、程度）、03 Claude（使用哪個引擎；登入帳號（訂閱，經由 Claude Code）或 API key；模型、effort；分別測試連線）、04 本機模型（清單與記憶體估算）、外觀。

## 學習秘書與 avatar

**第一版**：右上角一個 SVG 頭像（說話時嘴巴動畫）＋對話泡泡，依狀態給建議（「今天有 12 張卡片要複習」「選好了這篇，按產生教材」）。標記「文字模式」。

**第二階段（語音）**：
- 泡泡下方加「03 對話」區塊：按住說話 → Whisper（STT）→ 大腦回應並標出發音與文法問題 → Kokoro（TTS）播放。
- 盲聊模式：不顯示文字，只聽與說；結束後列出糾正清單，可一鍵加入生字或錯題本。
- 介面：音量波形、逐句字幕（可隱藏）、糾正以紙張上的波浪底線呈現（沿用 PaperComposer 段落檢查的樣式）。

**未來（數位人像）**：
- avatar 區塊換成可放大的人像視窗（右欄頂部或浮動視窗），嘴型同步由 TTS 的音素時間軸驅動。
- 設定存在工作區的 `avatar/`（外觀圖片、聲音、語速），可以跟著 private repo 同步。
- 介面保留「關掉人像，只用文字／語音」的選項，人像不是必要元件。

## 自動爬蟲

**第一版**：手動按「抓最新新聞」；robots.txt、間隔、User-Agent 已就緒。

**之後**：
- 排程：App 開著時每 N 小時抓一次（`sources.toml` 每個來源可設 `interval_hours`）；關閉時不在背景執行。
- 每日精選：依程度與興趣標籤（例如 tech、economy）為每個語言挑 1–2 篇，放在「今日」；可設定自動先產生教材（會花 API 費用，預設關閉，並顯示預估用量）。
- 去重：同一事件的英日報導以向量相似度歸為一組，可以做「同一則新聞的英日對照」教材。

## 資料串聯

目標：單字、文法、新聞、教材、錯題彼此連得起來，複習時看得到「這個字在哪裡學過」。

- **第一版已有**：單字與文法記錄 `source`（來自哪個 CSV、素材或教材檔）；錯題連回教材；教材連回原文；產生教材時把已會的單字傳給模型避免重複。
- **向量庫＋RAG（下一階段）**：歷史教材與新聞切段嵌入 LanceDB（本機、檔案型，放在設定資料夾，和 SQLite 一樣可從工作區重建）。用途：
  - 產生教材時找出以前學過的相關單字與文法，讓新教材「複習舊的、只加少量新的」。
  - 生字頁點一個字，列出它出現過的新聞句子（真實例句）。
  - 對話時讓大腦知道你最近學了什麼。
- **錯題 → 練習**：每週把錯題與遺忘次數高的卡片組成一份「弱點教材」，寄在週報裡。
- **Google**：複習時段與課程進行事曆；週報、提醒、課程確認走 Gmail。行程描述內附 App 的深連結（Tauri 版）。

## 主題

`web/themes.css`（載入在 `styles.css` 之後）定義 20 組配色：10 組深色、10 組淺色；每一邊都是 5 組**單色**（一個色相的深淺）＋ 5 組**搭配色**（三個主色組成一個有故事的組合）。每組本身就是深色或淺色，沒有另外的淺色／深色模式。

設定 → 外觀 只標「主題」，下面一格一張色票卡（深色兩列、淺色兩列，各自單色在前、搭配色在後），滑過／聚焦即預覽，點一下套用。選擇記在瀏覽器（`localStorage` 的 `jl.theme`），使用者已載入時也存進 `profile.toml` 的 `theme`，換瀏覽器也跟著人走（使用者的主題優先）。新使用者預設 **甜點禮盒**。合法的 id 只列在 `jl_core::workspace::THEMES`，`web/app.js` 的 `THEMES` 與 `themes.css` 必須一致（有測試檢查）。舊值會自動換成最接近的主題：第一版的橘／藍紫／綠（淺）→ 蜜桃薰衣草／薰衣草／薄荷，（深）→ 琥珀終端／霓虹夜市／駭客終端；其他已移除的 id 也各有對應。

色彩 token：原有的一組再加 `--accent-2`、`--accent-3`（各有 `-ink`、`-soft`）。`--accent` 仍是主要操作色（按鈕、焦點、目前分頁）；`-2`、`-3` 用在次要標記：左側導覽圖示、右側區塊編號、統計卡上緣與數字、複習卡、已選的興趣標籤、精靈的流程圖示、秘書頭像外圈、紙張的標題底線、單字、文法標題、題目左緣。單色主題的 `-2`、`-3` 是同一色相的深淺，所以任何元件都可以放心使用。新元件（等級環、積分條、技能條、任務卡）也用這三個色。

規則（每次改色都要重驗，20 組全部通過）：

- 背景、面板、表面、紙張都不是純黑或純白：深色不暗於約 `#12121a`，淺色不亮於約 `#fbf7f2`。
- 對比：本文對 `--bg`、`--panel` ≥ 7:1；`--muted` 對面板 ≥ 4.5:1；`--faint` ≥ 3:1（只用於裝飾或大字）；`--accent`、`--accent-2`、`--accent-3` 當文字或圖示對面板與背景 ≥ 3:1；每個 `-ink` 對它的主色 ≥ 4.5:1；`--ok`／`--warn`／`--err` 對面板 ≥ 4.5:1；`--paper-ink` 對 `--paper` ≥ 7:1。
- 紙張內的次要顏色（說明、讀音、翻譯、框線、選項底色、單字與文法標題的強調色）由 `--paper`／`--paper-ink` 以 `color-mix` 推出，深色紙與淺色紙都適用，當文字用時對紙張 ≥ 4.5:1。
