# 介面與功能設計

視覺語言沿用 PaperComposer：同一組色彩 token（深灰橘／藍紫黃／綠黑，各有深淺色）、同一套線條圖示、左側導覽＋中間「紙張」＋右側助手面板、設定視窗用分頁。JELearner 比 PaperComposer 多了秘書（avatar）、自動爬蟲、資料串聯，以下是整體規劃；標「第一版」的已完成，其他是之後的設計。

## 版面

```
┌ 頂列 ─────────────────────────────────────────────────────────────┐
│ JE/LEARNER  [EN|日本語]  （示範資料提示）        匯入 同步 設定    │
├ 左：導覽 ───┬ 中：目前頁面 ──────────────────┬ 右：學習秘書 ──────┤
│ 今日   (到期)│                                │ 〔avatar〕 對話泡泡 │
│ 新聞        │  教材＝紙張排版                 │ 01 產生教材         │
│ 教材   (數) │  其他頁＝卡片／表格              │ 02 匯入             │
│ ──          │                                │ （之後）03 對話     │
│ 生字   (數) │                                │                    │
│ 文法   (數) │                                │                    │
│ 錯題本 (數) │                                │                    │
│ 每週素材    │                                │                    │
│ ──          │                                │                    │
│ 信件與行事曆│                                │                    │
│ 工作區路徑  │ 狀態列：引擎、Google 模式、警告  │                    │
└─────────────┴────────────────────────────────┴────────────────────┘
```

- **語言切換**（頂列）決定所有頁面顯示哪個語言的資料、產生教材用哪個程度。
- **說明文字只放在 `?`**（hover 顯示），畫面保持乾淨，與 PaperComposer 相同。
- 視窗窄時先收右欄、再收左欄（Mac 主要用寬螢幕）。

## 頁面（第一版）

| 頁面 | 內容 |
| --- | --- |
| 今日 | 四個數字（待複習、新單字、複習次數與答對率、未訂正錯題）、翻卡複習（空白鍵翻面，1–4 評分）、最近的教材 |
| 新聞 | 依語言列出 feed 抓到的新聞與每週素材裡的文章；點一篇＝選給右邊「產生教材」；按「抓最新新聞」才連網 |
| 教材 | 列表；打開後以紙張排版：摘要、單字表（讀音、詞性、例句與翻譯）、文法解析、互動問答；可切換 Markdown 原文 |
| 生字／文法 | 表格、搜尋、表頭一列直接新增（寫入工作區的 `my-*.csv`）、刪除、到期狀態與來源檔 |
| 錯題本 | 題目、你的答案、正確答案、解說；回到教材；標記已訂正；可顯示已訂正 |
| 每週素材 | 已匯入的週次與項目數、JSON 格式說明、上傳 |
| 信件與行事曆 | 週報、把複習排進行事曆、排課並寄確認信；模擬模式顯示模擬寄件匣 |

設定視窗：01 工作區與同步（開啟／建立／下載、Git 狀態、同步、匯出紀錄、重新讀取）、02 個人（名字、週報信箱、程度）、03 Claude（key、模型、effort、測試）、04 本機模型（清單與記憶體估算）、外觀。

## 學習秘書與 avatar

**第一版**：右上角一個 SVG 頭像（說話時嘴巴動畫）＋對話泡泡，依狀態給建議（「今天有 12 張卡片要複習」「選好了這篇，按產生教材」）。標記「文字模式」。

**第二階段（語音）**：
- 泡泡下方加「03 對話」區塊：按住說話 → Whisper（STT）→ 大腦回應並標出發音與文法問題 → Kokoro（TTS）播放。
- 盲聊模式：不顯示文字，只聽與說；結束後列出糾正清單，可一鍵加入生字或錯題本。
- 介面：音量波形、逐句字幕（可隱藏）、糾正以紙張上的波浪底線呈現（沿用 PaperComposer 段落檢查的樣式）。

**未來（數位人像）**：
- avatar 區塊換成可放大的人像視窗（右欄頂部或浮動視窗），嘴型同步由 TTS 的音素時間軸驅動。
- 設定存在工作區的 `avatar/`（外觀圖片、聲音、語速），可以跟著 private repo 同步。
- 介面保留「關掉人像，只用文字／語音」的選項，人像不是必要元件。

## 自動爬蟲

**第一版**：手動按「抓最新新聞」；robots.txt、間隔、User-Agent 已就緒。

**之後**：
- 排程：App 開著時每 N 小時抓一次（`sources.toml` 每個來源可設 `interval_hours`）；關閉時不在背景執行。
- 每日精選：依程度與興趣標籤（例如 tech、economy）為每個語言挑 1–2 篇，放在「今日」；可設定自動先產生教材（會花 API 費用，預設關閉，並顯示預估用量）。
- 去重：同一事件的英日報導以向量相似度歸為一組，可以做「同一則新聞的英日對照」教材。

## 資料串聯

目標：單字、文法、新聞、教材、錯題彼此連得起來，複習時看得到「這個字在哪裡學過」。

- **第一版已有**：單字與文法記錄 `source`（來自哪個 CSV、素材或教材檔）；錯題連回教材；教材連回原文；產生教材時把已會的單字傳給模型避免重複。
- **向量庫＋RAG（下一階段）**：歷史教材與新聞切段嵌入 LanceDB（本機、檔案型，放在設定資料夾，和 SQLite 一樣可從工作區重建）。用途：
  - 產生教材時找出以前學過的相關單字與文法，讓新教材「複習舊的、只加少量新的」。
  - 生字頁點一個字，列出它出現過的新聞句子（真實例句）。
  - 對話時讓大腦知道你最近學了什麼。
- **錯題 → 練習**：每週把錯題與遺忘次數高的卡片組成一份「弱點教材」，寄在週報裡。
- **Google**：複習時段與課程進行事曆；週報、提醒、課程確認走 Gmail。行程描述內附 App 的深連結（Tauri 版）。

## 私人資料庫會越來越多的內容

| 類型 | 位置 | 說明 |
| --- | --- | --- |
| 自己想背的單字 | `vocab/*.csv` | 可放多個檔案（例如 `toeic-en.csv`、`jlpt-n2-ja.csv`），從試算表或單字卡 App 匯出 |
| 自己想學的文法 | `grammar/*.csv` | 同上 |
| 每週素材 | `materials/<週>/*.json` | 單字、文法、文章、備註混合；之後可加 `audio`（自己的錄音）與 `image` |
| 產生的教材 | `lessons/<lang>/*.md` | 可手動修改本文 |
| 紀錄 | `records/*.csv` | 複習進度、錯題本；之後加對話紀錄摘要 |
| 自訂提示詞 | `prompts/` | 覆蓋內建模板 |
| 人像與聲音 | `avatar/` | 之後 |

所有內容都是純文字（或之後的媒體檔），App 只新增、不覆蓋；資料庫只是索引與進度，隨時可重建。
