開始使用

你的英日語學習秘書

JELearner 會把新聞和你自己的單字、文法整理成每天的課程，陪你對話練習，並記錄進度。你的資料放在你自己的 private repo（私人工作區），本機資料庫隨時可以從那裡重建。

接下來幾步：選工作區、選或建立使用者、設定學習語言、連接 Claude、挑幾個有興趣的主題。每一步之後都能在設定裡改。

轉成多使用者結構

這個工作區是第一版的單人結構。JELearner 會把 vocab、grammar、materials、lessons、records 搬到 profiles/〈你〉/，在 Git repository 裡用 git mv 保留歷史，不刪任何檔案。搬完之後可以再加入家人。

先看看介面與示範資料，之後再到「設定 → 工作區與同步」連接你的私人工作區。

點自己的名字進入，或新增一位使用者。不需要密碼。

    要學哪些語言？兩種都可以勾。程度先自評大級，前幾課結束時會問你難度，再慢慢調整到剛好。

    產生教材與對話需要 Claude。登入的是你自己的帳號；同一台電腦的其他使用者會各自登入。

      也可以先略過，之後在「設定 → Claude」設定。
